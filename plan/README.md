# 📔 英语学习计划

> 本目录是英语学习的**计划与执行文档**，和仓库根目录的**工作台工具**（`index.html`）配套：
> 工具负责"每天怎么背"，这里负责"为什么这么背、学到什么程度、什么时候考试"。

> **当前定位：种子模板 / 备份。** 工作台里的「📔 计划」tab 现在把计划**按账号**存在 Supabase（`user_plan` 表），每个用户第一次打开时可选择"复制本目录的模板"或"从空白开始"，之后在 App 内编辑、自动云同步。本目录不再直接展示给所有人，只当模板源和离线备份。

## 和工作台的分工

- **工作台（`index.html`）已经自动实现**：每日目标词数、艾宾浩斯 1→3→7→15→30 复习、加权抽词、慢速朗读、连续打卡、三明治三步、当天/到期双复习、半熟回炉、当日错词补刀。
- **本目录负责工具做不到的**：跟读 shadowing、睡前技术日记、雅思模考与考试节点、2027 年的口语课与写作批改。
- 计划里出现的参数（每日 10 词、1/3/7/15/30、加权比例、朗读语速）**以工作台「设置」为准**，文档只描述用法；若两边不一致，改工作台或改文档，别让两份各说各话。
