# 英语工作台内容说明

这个目录只保留工作台实际展示的 4 份内容，避免打开十几份计划后仍不知道今天做什么。

| 文件 | 工作台标签 | 用途 |
|---|---|---|
| [今日学习.md](./今日学习.md) | 今日学习 | 解释按账号等级、目标、强度和日期自动生成任务的规则 |
| [学习路线.md](./学习路线.md) | 学习路线 | A2 起点、每周循环、12 个月阶段和复习规则 |
| [english_diary.md](./english_diary.md) | 日记 | 每个账号自己的英文输出，登录后可编辑和云同步 |
| [README.md](./README.md) | 说明 | 当前页面 |

## 使用顺序

1. 打开工作台的「🧭 今日英语」。
2. 进入「今日学习」，点当天材料链接。
3. 按页面给出的顺序完成，不再临时搜索文章。
4. 回到页面勾选课文、听力跟读；词汇复习由工作台自动点亮。
5. 每周 3 次进入「日记」，完成 5 句或 30–60 秒口述稿。

每个账号独立选择 **A1 / A2 / B1 / B2**，课程采用**美式英语**。难度根据实际听懂比例、完成时间和输出表现调整，不按日期自动升级。

词库开发和审计属于维护资料，已移到 [`docs/词库维护说明.md`](../docs/词库维护说明.md)，不会再混进每日学习页面。
