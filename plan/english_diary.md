## 2026-08-31

[ORIGINAL]
today i review fifteen question about hash and list. what's more, i learn new
knowledge about stack

[ERRORS]
- "today i review" → "Today I reviewed"  （日记记过去用过去式；I / 句首大写）
- "fifteen question" → "fifteen questions / problems"  （复数）
- "hash and list" → "hash tables and linked lists"  （list 单独易歧义，算法里是 linked list）
- "what's more," → "What's more,"  （句首大写 + 加逗号）
- "i learn new knowledge about stack" → "I learned about the monotonic stack"
  （过去式；"learn new knowledge" 啰嗦，改用 learned about；stack 用 stacks / the stack）

clean version:
Today I reviewed fifteen problems on hash tables and linked lists. What's more,
I learned a new pattern: the monotonic stack.

[TERMS]
- 单调栈 = monotonic stack
  A monotonic stack keeps its elements in sorted order (increasing or
  decreasing), so it can find the next greater/smaller element in O(n) time.
  Today: decreasing stack finds next greater (#739); increasing stack finds
  next smaller (#84 / #85).

## 2026-09-02

[ORIGINAL]
I didn't learn something new today, because my job is very busy. I wish i can
finish all of the question tommorrow

[ERRORS]
- "learn something new" → "learn anything new"  （否定句用 anything，不用 something）
- "my job is very busy" → "I was very busy with my job"  （job 本身不会 busy，是"人"忙；且与前半句过去时一致用 was）
- "I wish i can" → "I wish I could"  （wish 后用虚拟语气 could；I 须大写）
- "all of the question" → "all of the questions / all the problems"  （question 用复数；算法题常说 problems）
- "tommorrow" → "tomorrow"  （拼写）

clean version:
I didn't learn anything new today, because I was very busy with my job. I wish
I could finish all the problems tomorrow.
