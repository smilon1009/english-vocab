# 每天怎样让 CodeBuddy 带我学英语

用 CodeBuddy 打开 `C:\project\english-vocab`。根目录 `CODEBUDDY.md` 会自动提供教练规则；规则修改后新建一次对话。

## 每日开场

```text
今天是____，我有____分钟。请读取 CODEBUDDY.md、plan/完整英语学习系统.md 和 plan/12周英语执行计划_2026-09-28.md。根据今天星期几，只给我一个完整任务。

我的主要目标是工作英语、未来外企和 IELTS。请让我先完成输入或输出，再纠正；不要一次生成很多新词或直接替我写答案。今天结束时记录：完成了什么、三个高价值表达、一个主要错误、下次复验内容。
```
## 精听日

```text
这是今天的音频原文/链接：____。先不要翻译全文。请按盲听主旨、细节问题、核对文本、逐句跟读、60秒复述带我完成；一次只进行一步。
```

## 阅读日

```text
这是今天的文章：____。我会先在不查词的情况下写主旨。请等我回答后，用三个问题检查理解，只挑最多五个真正影响理解或值得复用的词组。
```

## 写作日

```text
主题是____。请先让我写五句话。收到后不要直接重写全文，先指出最多三个关键问题并解释，让我自己修改；第二版后再给自然表达，并要求我用其中三个表达重新造句。
```

## 口语日

```text
请围绕____和我进行五轮英文问答，一次只问一个问题。先回应我的内容，不要每句打断；每轮只纠正一个最重要问题，最后总结两个反复问题和三句更自然的表达。
```
