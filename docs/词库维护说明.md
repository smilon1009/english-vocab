# 词库维护说明

本文件供维护工作台词库时使用，不属于每日学习计划。

## 当前状态

- IELTS 没有官方封闭的“全部单词”清单。
- 现有卡片来自旧词库，需逐条核验释义、词性、例句、难度和重复项。
- NGSL（通用高频）和 NAWL（学术词汇）用于覆盖分析，不等于可以未经审核直接导入。
- 覆盖报告位于 `data/coverage_report.json`。

## 新词进入工作台前的要求

1. 词头和词性正确；
2. 中文释义与英文提示一致；
3. 例句自然、难度适合当前阶段；
4. 没有重复词条或明显词形错误；
5. 来源和许可可以追溯；
6. 通过仓库中的审计工具。

扩充时优先补通用高频和学习者当前材料中反复出现的词。每批少量审核、测试后再发布，避免为了卡片数量降低质量。
